## Reproduction

From the authoritative workspace, with the existing Atlas server running:

```sh
./scripts/package-runtime pm tools/remotion-style-atlas exec node --import tsx tests/mechanisms.ts
./scripts/package-runtime pm tools/remotion-style-atlas exec node --import tsx tests/original-demos.ts --previews
./scripts/package-runtime pm tools/remotion-style-atlas exec node --import tsx --test tests/original-demo-integrity.ts
./scripts/package-runtime pm tools/remotion-style-atlas exec node --import tsx scripts/capture-technology.ts SA-229 SA-230 SA-231 SA-232 SA-233 --previews
.venv/bin/python scripts/test_researched_mechanisms.py
```

Rendered media hashes and source fingerprints use the existing `src/technology/evidence.json`. The integrity test checks actual H.264 streams, dimensions, frame counts, no audio, source hashes and byte-identical built source downloads. Browser checks exercise actual results, parameter contributions, CJK overflow rejection/recovery, desktop/portrait bounds, reduced motion, repeated/backward time, replay, catalog search/pagination and resolved source links. Repeated seek pixels and SVG states are exact; restarted SVG is exact, with a narrowly bounded <0.2% raster edge difference and ≤16/channel allowance for observed browser compositor antialiasing after active playback.
